# Quality Formal Shoes

Mobile-first React/Vite demo storefront for Quality Formal Shoes, Eastgate Market, Stall E3, Harare.

## Deploy
- `npm install`
- `npm run build`
- Deploy the generated `dist/` folder to Cloudflare Pages, or connect this repository to Cloudflare Pages with the build command `npm run build` and output directory `dist`.

## Notes
Product photography is demonstration imagery. Availability, pricing and stock are intentionally not invented. Customers are directed to WhatsApp to confirm current products.
